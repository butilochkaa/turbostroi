# turbostroi v2 (fork) — v0.1-beta

> ⚠️ **важно: это ранняя бета-версия (v0.1-beta)**.  
> код находится в активном тестировании и доработке, возможны шероховатости на экзотических конфигах. фиксы и улучшения будут допиливаться в следующих апдейтах.

форк турбостроя с нормальным распределением ядер и фиксами потоков.  
оригинал: https://github.com/kosmik641/gm_turbostroi

готовые бинарники лежат в папке `release/`:
- `release/gmsv_turbostroi_win32.dll` (windows x86)
- `release/gmsv_turbostroi_linux.dll` (linux x86)

## установка

закинуть нужную dll в папку сервера:
- `garrysmod/garrysmod/lua/bin/`
- если папки `bin` внутри `garrysmod/lua/` нет — просто создай её руками.

## фичи этой версии

- **человеческие ядра**: вместо калькулятора битовых масок можно писать диапазоны (`0-1`, `2-11`), списки (`0,2,4`) или просто `all`. старые маски числами тоже работают.
- **`turbostroi_train_spread 1`**: каждый вагон жестко садится на свое выделенное ядро по кругу (round-robin pinning). потоки не скачут между ядрами, l1/l2 кэш не сбрасывается, убирает просадки фпс при куче составов.
- **смена ядер на лету**: меняешь квары прямо во время игры — поезда мгновенно пересаживаются на новые ядра без рестарта сервера и без удаления вагонов.
- **пофикшен 32-битный баг**: на 32-поточных камнях сдвиг маски больше не улетает в ub/ноль.
- **умные дефолты**: если конфига нет, турбострой сам смотрит сколько ядер на тачке и раскидывает нагрузку (сервер на 0-1, поезда на остальные).

## конфиг (`garrysmod/cfg/turbostroi.cfg`)

```kv
"Turbostroi"
{
	"turbostroi_main_cores"		"0-1"
	"turbostroi_train_cores"	"2-11"
	"turbostroi_train_spread"	"1"
	"turbostroi_unpack_lua"		"1"
}
```

---

## команды и квары

- `turbostroi_main_cores <значение>` — ядра под главный поток сервера (srcds, физика, сеть, тикрейт).  
  *примеры:* `"0-1"` (ядра 0 и 1), `"0"` (только нулевое), `"all"` (все ядра).

- `turbostroi_train_cores <значение>` — ядра исключительно под симуляцию поездов (системы, электрика, пневматика).  
  *примеры:* `"2-11"` (со 2 по 11), `"2,4,6,8,10"` (только физ. ядра без HT), `"all"`.

- `turbostroi_train_spread <1/0>` — режим распределения вагонов по ядрам:  
  * `1` (**рекомендуется**): round-robin pinning — каждый вагон жестко привязан к отдельному ядру по очереди.  
  * `0`: общая маска — планировщик ос сам решает, куда перекидывать потоки.

- `turbostroi_clear_cache` — очистить кэш lua-скриптов систем в оперативной памяти (нужно при обновлении скриптов без рестарта сервера).

- `turbostroi_clear_print` — мгновенно сбросить очередь сообщений в консоль, если кривой вагон заспамил сервер.

- `metrostroi_turbostroi_run_disable` — вырубает команду `metrostroi_turbostroi_run` до перезапуска сервера (защита от выполнения lua-строк).
